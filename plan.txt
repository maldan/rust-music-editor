Звук инструментов — что не хватает и куда копать
================================================

Хор, дилей и катофф почти не делают инструмент.
Они красят уже готовый звук.

Уникальность сидит в источнике и в том, как он меняется
за первые 50–200 мс ноты.

Сейчас типичный патч: Voice (пил/квадрат) → фильтр → хор/дилей.
После фильтра все волны схлопываются в один и тот же «синт».


Из чего складывается «другой инструмент»
----------------------------------------
Любой живой патч — слои с разной жизнью, не одна волна.

  Клик / атака  — шум 5–30 мс, щелчок, короткий семпл.
                  Мозг узнаёт инструмент по атаке.

  Тело          — осциллятор / FM / струна. Это тембр.

  Движение      — фильтр, PWM, FM-индекс, питч.
                  Звук не стоит на месте.

  Воздух        — шум, высокие, лёгкий хор. «Живость».

  Пространство  — реверб/дилей чуть-чуть. Сцена, не характер.

Без атаки и без движения все патчи звучат как одна пила с соусом.


Что крутить уже сейчас (без новых нод)
--------------------------------------

1. Фильтр обязан ехать
   Note Gate → Smooth (20–80 мс вверх) → cutoff.
   Короткий спад cutoff = плак/бас. Долгий = пэд.
   Стоящий катофф = «один и тот же звук».

2. Два источника, разные роли
   Не один Voice.
   Пила в фильтр + квадрат на октаву ниже (sub) + Noise на 50 мс через гейт.
   Суб даёт вес, шум — характер атаки.

3. FM как тембр, не как вибрато
   Osc A → вход fm у Osc B.
   Глубину тоже надо огибать, иначе просто гудение.
   Лёгкий FM на квадрате = клавиша/колокол, сильный = бас/металл.

4. Питч-щелчок
   На атаке частота чуть вверх и сразу вниз.
   Кик, бас 303, плак — это почти всегда питч-энв, не ещё один хор.

5. PWM + unison только точечно
   PWM с LFO = электроорган.
   Unison 4–8 + 8–18 центов = суперпил.
   Unison + хор + дилей на всё = каша.

6. Не крась всё FX
   Инструмент собирай сухим.
   Хор/дилей — в конце и слабо.
   Иначе все пресеты становятся «широкий синт в ванной».

7. Гитара / Piano / семпл как тело
   Karplus + лёгкая дисторшн + короткий реверб = уже не пила.
   Семпл атаки поверх Voice — дешёвый путь к уникальному тембру.


Практичный каркас инструмента
-----------------------------

  notes ─┬─ Voice (тело, своя ADSR)
         ├─ Voice/Osc noise (только атака, gain с Note Gate)
         ├─ Osc sub (pitch 0.5)
         └─ Note Gate → Smooth → Filter cutoff
                ↓
           Distortion чуть-чуть → EQ → dry out

Пространство — отдельным хвостом, не внутри каждого инструмента.


Чего не хватает в движке (по важности)
--------------------------------------

1. Envelope-нода (ADSR → число, триггер с нот).
   Без этого cutoff / FM / питч не накрутишь нормально.
   Note Gate + Smooth — костыль.

2. Filter envelope + pitch envelope прямо на Voice.
   Даже два кноба env→cutoff и env→pitch делают кучу пресетов.

3. Семплер как голос: нота → питч семпла, loop, start point.
   Сейчас семпл — это трек, не инструмент.

4. Шум с окраской (pink/blue) и click.
   Белый шум через LPF ≠ щётка / хай-хэт / атака пианино.

5. Wavetable / morph или хотя бы 2–3 кастомные волны.
   Пять аналоговых форм быстро кончаются.

6. Formant / 3 bandpass (гласные). Сразу «голос», не синт.

7. Velocity. Без динамики все ноты одной силы — пластилин.

8. Сатурация до фильтра и после — разный характер.
   Один Distortion в конце всех уравнивает.

Не надо сразу Serum.
Порядок: огибающая CV → семплер по нотам → питч-энв.
Это три вещи, после которых патчи перестанут быть близнецами.


Как думать пресетами
--------------------
Задай характер словами, потом крути только 2–3 параметра.

  Плак     — пила, cutoff env 80→2 кГц за 120 мс, amp decay короткий, без реверба.
  Пэд      — два осца ±7 центов, медленный LFO на cutoff, attack 0.4 с, хор едва.
  Бас      — квадрат + sub, питч-энв 30 мс, дисторшн до фильтра, без хора.
  Колокол  — FM 2:1, индекс падает, длинный релиз, почти нет фильтра.
  Орган    — PWM медленный LFO, без фильтра, короткая атака.

«Уникальный» тембр: чужой семпл атаки 20–80 мс поверх любого из этих.


Следующий шаг в коде (когда вернёшься)
--------------------------------------
Envelope-нода в граф: CV из нот на cutoff / FM / питч.
Самый большой скачок качества при минимальном коде.
